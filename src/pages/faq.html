FAQ

Perguntas frequentes sobre o sistema

O que é o Septem Racing? +
O Septem Racing é um sistema de gestão voltado para equipes de automobilismo. Permite gerenciar carros, corridas, pilotos e equipes em uma única plataforma digital integrada e intuitiva.
Como criar uma conta? +
Acesse a página de Cadastro, preencha seus dados (nome, email e senha) e clique em "Cadastrar". Após o cadastro, você poderá acessar todas as funcionalidades do sistema.
Como cadastrar um novo carro? +
Acesse a seção Cars no menu lateral e clique em "+ Adicionar Carro". Preencha o chassis, modelo, motor e piloto associado. Os dados ficam disponíveis em tempo real no sistema.
Como acompanhar uma corrida em tempo real? +
O Dashboard exibe dados ao vivo durante uma corrida: tempo de volta, gap para o líder, posição no circuito, velocidade por setor e muito mais. Mantenha a página aberta para atualizações em tempo real.
O sistema funciona no celular? +
Sim! O Septem Racing foi desenvolvido com design totalmente responsivo. Funciona em smartphones, tablets e desktops, adaptando o layout automaticamente para cada dispositivo.
Quais tecnologias são utilizadas? +
O frontend utiliza HTML5, CSS3 e JavaScript puro. O backend é construído com Node.js + Express.js. O banco de dados é MySQL. A comunicação entre frontend e backend é feita via API REST.
